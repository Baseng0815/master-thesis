\section{Architecture Overview}\label{sec:impl-architecture}

\input{figures/system-architecture}

Our fuzzer is implemented in the Rust programming language.
We chose Rust as a language due to its safety guarantees, thereby significantly
reducing the potential for memory errors, as well as its high performance, ease
of use and large ecosystem of libraries.
The project is split into three separate components.
The execution environment is provided by \emph{MOGI}\index{MOGI}, an emulation framework that
provides deterministic execution capabilities, snapshotting, and cross-architecture emulation.
We also provide a custom implementation of the EfficientZero algorithm in Rust.
This has the advantage of not needing to rely on interfacing with the existing Python
implementation, which in general is very slow.
It also makes it easier to include EfficientZero in the overall architecture.
Finally, we provide the actual fuzzer, \emph{mugiwara}\index{mugiwara}, which implements the interface
required by the EfficientZero learner and drives the execution of PUTs using MOGI.
In addition, it contains utility functions that are shared between different PUTs
like instrumentation and a model of a seed corpus.

We chose to develop these three components separately to enable a clean architectural
split.
Although MOGI was created for fuzzing, it is a general emulation framework
that can serve other purposes.
In addition, the EfficientZero algorithm requires the environment to
implement only a minimal set of functions, making it applicable to
fuzzing as well as general RL environments like the Atari
100k benchmark suite.
